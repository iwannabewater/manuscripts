# 场外纳斯达克 100 基金推荐排名 2026

面向中国内地普通投资者的人民币场外纳斯达克 100 QDII 基金筛选报告。

## 文件

- `index.html`：A4 阅读版源文件。
- `nasdaq100-otc-fund-ranking-2026.pdf`：PDF 成品。
- `sources.md`：研究口径、来源与证据分层。
- `data/fund-screen-2026-06-17.json`：候选基金原始抓取字段。
- `data/fund-ranking-2026-06-17.csv`：主榜排序与评分字段。

## 口径

- 研究对象：人民币场外公募 QDII、ETF 联接或指数基金份额，标的为纳斯达克 100。
- 证据日期：基金交易状态和净值展示截至 2026-06-16 至 2026-06-17；规模截至 2026-03-31；QDII 额度表发布时间为 2026-05-29。
- 推荐含义：在公开费率、规模、限购和当前可申购状态下的研究型排序，不构成个性化投资建议或收益承诺。
