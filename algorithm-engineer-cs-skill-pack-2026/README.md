# Algorithm Engineer CS Skill Pack 2026

面向大模型、搜索、广告、推荐与算法平台工程师的 CS / 软件工程技能包。

本作品把顶尖算法工程岗位中的高频工程能力拆成可学习、可验证、可落地的体系：代码协作、离线数据、实时流、训练评测、特征与标签、模型服务、线上实验、稳定性、安全治理、GPU 系统和成本管理。

## Files

- `index.html`: 可读与可打印源文件。
- `algorithm-engineer-cs-skill-pack-2026.pdf`: PDF 成品。
- `sources.md`: 资料来源、口径与边界。
- `fonts/`: PDF 复现所需字体。

## Scope

资料口径截至 2026-05-31。正文优先采用公开一手来源：Google ML / SRE / Engineering Practices、Meta Engineering、OpenAI 公开资料、Anthropic 公开岗位与 Responsible Scaling Policy、NVIDIA 官方文档、ByteDance / CloudWeGo / Monolith 开源材料，以及 Apache、Kubernetes、Git、GitHub、MLflow、Kubeflow、Ray、vLLM、KServe 等官方文档。

本文不是某家公司内部培训材料，也不声称覆盖任何非公开制度。它的目标是把真实生产中的算法工程工作面整理成一套可执行的能力地图。
