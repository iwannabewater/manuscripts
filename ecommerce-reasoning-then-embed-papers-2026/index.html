01 · 怎么用这份读单

这不是“最新多模态论文合集”，而是围绕一条方法主线的读单：模型是否先把任务相关结构显式化，再把结果压成可检索向量。电商图搜里，这条主线对应属性推理、区域定位、意图挖掘、组合修改意图，以及能否在固定延迟预算内完成。

读什么

方法：推理如何进入表征；数据：商品属性、难负样本、修改文本；系统：召回、重排、策略路由、延迟预算。

不读什么

不把通用 benchmark 第一名直接当作可上线图搜方案；不把作者报告的 GMV/CTR 写成独立审计结论。

怎么挑

做同款/近同款：P01-P03；做难 Query 自适应：P07/P11；做改颜色/改材质：P12-P13；做高 QPS：P14-P15。

预印本纪律

2026 年清单中多数工作仍是 arXiv 预印本。正文把它们当作方法与公开实验信号；录用状态、线上收益和跨平台可迁移性分开表述。REVISION 为 WSDM 2026 Full Paper，其余以 arXiv 为准。

03 · 一、直接面向电商图搜：优先精读

这一层最贴近生产图搜：商品多图文、裁剪 Query、复杂背景、同款近同款、召回后重排、无点击闭环。建议按 MOON 演进线 + 工业系统线两条并行读。

01
MOON3.0: Reasoning-aware Multimodal Representation Learning for E-commerce Product Understanding
精读

arXiv:2604.00513 · 电商商品统一表征 · 先推理、后表征

思路
典型“先推理、后表征”。先从商品图像和标题生成类别、颜色、材质、设计元素等结构化属性，再通过 <emb> 表征、原始图文多头融合和 FIRE 细粒度残差增强，得到 256 维向量。
收益
相较 MOON2.0，MBE3.0 上 Image->MM R@10 从 50.41 提升至 56.39，Text->MM 从 35.33 提升至 48.10；分类准确率从 67.27 提升至 86.40，属性准确率从 36.36 提升至 49.92。
模态
图片->图文商品、文本->图文商品、图文->图文、文搜图、图搜文本。
推荐
当前最贴近“电商商品多模态统一表征 + 推理召回”的工作。
02
TIGER-FG: Text-Guided Implicit Fine-Grained Grounding for E-commerce Retrieval
精读

arXiv:2605.18434 · 裁剪 Query 非对称 · 隐式目标定位

思路
针对“裁剪商品 Query 图 vs 带背景的完整商品图 + 文本”这一真实图搜非对称问题，用商品文本引导候选图像进行隐式目标定位，无需额外检测框；再通过空间一致性和相似度结构双重蒸馏强化细粒度匹配。
收益
在标准和复杂背景测试集上，相对最强基线 Recall@1 分别提升 6.1 和 34.4 个百分点；Query 侧仅 85.7M 参数，输出 256 维向量。
模态
裁剪图片 Query -> 完整商品图片 + 标题 / 属性。
推荐
对拍照图、子图、复杂背景、多商品干扰等电商图搜问题最直接。
03
Pailitao-VL: Unified Embedding and Reranker for Real-Time Multi-Modal Industrial Search
工业

arXiv:2602.13704 · 阿里拍立淘 · 召回 + 重排 + 实时部署

思路
阿里拍立淘工业系统。Embedding 从相对式对比学习转为超大规模 Absolute ID Recognition，让每个高纯商品实例对应稳定的全局语义原型；Reranker 从 pointwise 判断转为 chunk 内比较与跨 chunk 绝对分数校准。
收益
公开线上 A/B 中，部分 AI 搜索场景报告约 20% GMV 增长；Embedding 与 listwise reranker 平均延迟分别压至约 67 ms 和 76 ms。
模态
多模态商品召回、同款 / 近同款检索、召回后高精度重排。
推荐
最值得参考的完整“召回 + 重排 + 线上 A/B + 实时部署”工业方案。
04
MOON / MOON2.0：MOON3.0 的基础演进路线
演进

系列演进 · 建议 MOON -> MOON2.0 -> MOON3.0 连读

MOON
使用生成式 MLLM 学习商品统一表征，引入 guided MoE、核心视觉区域识别及电商难负样本策略，解决商品多图、多文本的 many-to-one 对齐问题。
2.0
进一步解决图文训练中的模态不平衡、商品内部图文关系利用不足以及电商噪声问题。
模态
商品多图 + 标题 / 属性，支持跨模态检索、分类和属性预测。
推荐
按 MOON -> MOON2.0 -> MOON3.0 阅读，可完整理解阿里从生成式商品表征到推理式商品表征的演进。

工业报告补充 · MOON Embedding

MOON Embedding 工业报告称，该系列已部署于淘宝搜索广告的召回、相关性和排序阶段，并报告整体 CTR 预测累计提升约 20%。该数字是 MOON 系列多次迭代的系统收益，不能单独归因于 MOON3.0 或某个召回模型。入口：MOON Embedding Technical Report (arXiv:2511.11305)。

05
Text-Guided Visual Representation Learning for Robust Multimodal E-Commerce Recommendation
抗噪

arXiv:2605.17366 · TGQ-Former · 元数据引导视觉 token

思路
提出 TGQ-Former，用商品标题、类目和结构化元数据引导视觉 token 选择；同时保留 metadata-guided 与 exploratory 两路视觉 query，并利用可靠性双门控抑制促销文字、背景和装饰噪声。
收益
在真实大规模全库商品检索中，平均 Hit Rate@100 提升 6.04%。
模态
商品图片 + 标题 / 类目 / 属性 -> 商品 I2I 或多模态召回。
推荐
非常适合解决商详海报、促销角标、背景复杂、商品主体不突出等线上噪声问题。
06
REVISION: Reflective Intent Mining and Online Reasoning Auxiliary for E-commerce Visual Search System Optimization
系统

arXiv:2510.22739 · WSDM 2026 Full Paper · 无点击闭环

思路
针对图搜无点击请求，离线从历史 Query 图、浏览商品和行为日志中挖掘用户隐式意图；线上由轻量推理模型生成优化计划，并动态调度搜索链路中的策略。
收益
论文报告可提高隐式意图挖掘效率并显著降低无点击率，但摘要未披露统一的具体百分比。
模态
Query 图片 + 历史商品 + 用户行为；更偏系统策略优化，而非单一 embedding。
推荐
适合研究图搜场景识别、兜底通道、策略路由以及无点击问题闭环。

04 · 二、“先推理后表征”通用方法：重点迁移

这一层提供可迁移的 Reasoner->Embedder 训练与推理范式。对电商图搜，价值不在 benchmark 名次本身，而在：如何让 CoT 服务正负商品区分、何时开推理、如何控制延迟。

07
Think Then Embed: Generative Context Improves Multimodal Embedding
基线

arXiv:2510.05014 · Reasoner + Embedder · MMEB-V2

思路
Reasoner 先生成与检索任务相关的 Embedding-Centric Reasoning，Embedder 再联合原始输入和 reasoning 生成向量；同时研究“大 Reasoner + 小 Embedder”、蒸馏 Reasoner 以及统一模型等配置。
收益
论文在 MMEB-V2 上报告当时领先表现，证明显式 reasoning 对复杂多模态约束和组合意图尤其有效。
模态
图片、文本、视频、视觉文档及图文组合 Query。
迁移
可作为 MOON3.0 之外最标准的 Reasoner->Embedder baseline。
08
UME-R1: Exploring Reasoning-Driven Generative Multimodal Embeddings
双通道

arXiv:2511.00405 · discriminative + generative embedding

思路
同一模型同时输出直接 discriminative embedding 和“生成 reasoning 后得到的 generative embedding”；采用 Cold-start SFT + RL，并探索多次采样产生多个 reasoning / embedding。
收益
相对相同数据规模的 DUME，图像、视频和视觉文档任务总分分别提升 4.1、9.0 和 11.1；相对 VLM2Vec-V2 总体提升 2.1。
模态
图像、视频、视觉文档、图文组合检索。
迁移
适合探索图搜中“直接向量 + 推理向量”双通道召回及 inference-time sampling。
09
Embed-RL: Reinforcement Learning for Reasoning-Driven Multimodal Embeddings
RL

arXiv:2602.13823 · Embedder-Guided RL · T-CoT

思路
提出 Embedder-Guided RL，由 Embedder 直接评价 Reasoner 生成的 CoT 是否有利于检索；T-CoT 强制推理指出图片、文本中的具体检索证据，而不是只生成泛化解释。
收益
在 MMEB-V2 和 UVRB 上超过其对比的早期 reasoning embedding 模型，重点提升跨模态一致性和细粒度匹配。
模态
图片 / 图文 Query -> 图片、文本或多模态候选。
迁移
非常适合训练商品属性 reasoning，使其真正服务于正负商品区分。
10
MMEmb-R1: Reasoning-Enhanced Multimodal Embedding with Pair-Aware Selection and Adaptive Control
难负

arXiv:2604.06156 · pair-level 监督对齐 · 自适应启用 reasoning

思路
指出普通 CoT 是 instance-level，而对比学习是 query-target pair-level，二者存在监督错位；通过 pair-aware reasoning selection、反事实比较和自适应控制，只在 reasoning 能改善正负间隔时使用它。
收益
论文报告在提高检索准确率的同时，相对 UME-R1 获得约 2.5x 推理延迟改善。
模态
通用图片、文本、视频、视觉文档检索。
迁移
适合电商难负样本训练，避免 reasoning 只学到格式、类目等无判别信息。
11
Think When Needed: Adaptive Reasoning-Driven Multimodal Embeddings
生产

arXiv:2605.14448 · Routing Gate · Reasoning LoRA + Embedding LoRA

思路
共享冻结的 MLLM backbone，分别挂载 Reasoning LoRA 和 Embedding LoRA；Routing Gate 自动决定当前样本走直接 embedding 还是先生成 CoT，并用固定 Embedder 作为稳定 RL reward 环境。
收益
在 MMEB-V2 的 78 个任务上报告领先结果，仅增加 backbone 约 3%-5% 参数，并最多减少 50% reasoning token。
模态
通用多模态召回。
迁移
很适合图搜生产系统--干净商品图直接编码，截图、复杂背景、组合约束等困难 Query 才启动推理。

05 · 三、找相似+修改意图：重点关注 CIR

Composed Image Retrieval 对应“保持版型，把红色改成黑色”“保留鞋型，去除图案”一类需求。推理不再只是解释，而是要决定保留什么、删除什么、新增什么。

12
CIR-CoT: Towards Interpretable Composed Image Retrieval via End-to-End Chain-of-Thought Reasoning
CIR

arXiv:2510.08003 · FashionIQ / CIRR / CIRCO

思路
输入参考图片和修改文本，依次生成 Caption、Reasoning、Conclusion，最后将目标检索意图压缩到专用 embedding。
收益
在 FashionIQ、CIRR 上取得有竞争力的结果，并在未参与训练的 CIRCO 上表现出较强泛化。
模态
参考图片 + 修改文本 -> 目标图片。
场景
“保持版型，将红色改为黑色”“保留鞋型，去除图案”。
13
MCoT-MVS: Multi-level Vision Selection by Multi-modal CoT Reasoning for Composed Image Retrieval
SOTA

arXiv:2603.17360 · 视觉区域选择受 reasoning 控制 · 公开代码与模型

思路
MLLM 先输出“应保留、应删除、目标新增”的文本线索，再用这些线索选择参考图中的 patch-level 和 instance-level 视觉特征，最后融合修改文本和目标描述。
收益
论文在 CIRR 和 FashionIQ 上报告新的 SOTA，并公开代码和模型。
模态
参考图 + 商品修改描述 -> 目标商品图。
迁移
比仅将 CoT 文本拼入 embedding 更进一步，因为 reasoning 会反向控制视觉区域选择。

06 · 四、低延迟前沿探索

显式文本 CoT 在检索准确率上有效，但对高 QPS 图搜过重。这一层探索把“想”放进 latent space：固定 token 预算、单次前向、可蒸馏的 Query Tower。

14
TTE-Flash: Accelerating Reasoning-based Multimodal Representations via Think-Then-Embed Tokens
加速

arXiv:2605.16638 · latent think tokens · 可解释

思路
不再自回归生成长文本 CoT，而是在同一 backbone 中使用 latent think tokens，再由 embedding token 汇总。
收益
TTE-Flash-2B 在 MMEB-V2 上超过其显式 CoT 对照模型，同时 latent token 可通过文本和视觉方式进行解释。
模态
通用图片、文本、视频及视觉文档。
价值
适合高 QPS 图搜，把几十步文本 decode 压缩为固定 token 的一次前向传播。
15
LaME: Learning to Think in Latent Space for Multimodal Embedding
蒸馏

arXiv:2606.13061 · 信息瓶颈 · 无需 CoT 文本标签

思路
用固定数量的 learnable reason tokens 作为信息瓶颈，在 latent space 完成 reasoning；无需 CoT 文本标签，也无需自回归生成。
收益
核心优势是单次 forward、固定计算预算，并降低 embedding 对教师 CoT 质量的依赖。
模态
通用多模态 embedding。
价值
适合长期研究“MOON3.0 推理能力蒸馏到低延迟 Query Tower”。

推理有效但 QPS 扛不住 P11, P14, P15 自适应开推理；latent think 固定预算蒸馏到 Query Tower 全量 Query 自回归长 CoT

一条可执行的系统拼法

主干：可预计算 item embedding + ANN 召回 + listwise 重排(P03)。Item 侧吸收属性推理与抗噪(P01 / P05)。Query 侧默认直出向量，困难样本再开推理(P11)，中长期用 latent think 蒸馏(P14 / P15)。裁剪与复杂背景走细粒度 grounding 通道(P02)。无点击与策略路由单独成系统层(P06)。CIR 作为“修改意图”产品入口，不与同款召回混为一谈(P12 / P13)。

08 · 来源、边界与自检

本读单按作者公开材料整理思路、收益与适用模态。线上 GMV、CTR、延迟等数字均为作者报告，不是独立审计；预印本工作以方法与公开实验为主，不默认等同正式录用结论。

必须分开写的三类信号

  • 离线指标：MBE3.0、MMEB-V2、FashionIQ、CIRR、Recall@1 / H@100 等，便于方法比较，不能单独证明线上可买与可部署。
  • 工业 A/B：如 Pailitao-VL 部分场景 GMV、MOON Embedding 全链路 CTR，属于高价值产业信号，迁移时要对照数据治理、品类与延迟预算。
  • 系统层收益：REVISION 的无点击下降等，属于链路策略结果，不宜直接写成 embedding 模型增益。
