结论先行

DOPD 的价值不在于把更多特权信息塞给教师或学生，而在于承认特权上下文会制造“看似更强”的监督幻觉，并用 token 级别的优势差值和相对概率，把可迁移能力、信息不对称和学生自洽探索拆开处理。作为 OPD 的 2026 年增量，它提出的问题足够准确，方法足够工程化，实验覆盖也明显强于一般蒸馏论文。

本文聚焦一个审稿问题：DOPD 是否真正解决了 privileged-context OPD 的核心失败模式，还是只是一次更复杂的蒸馏调参。结论是前者更接近事实，但仍需要独立代码、训练数据和成本曲线来完成工程闭环。

01

Executive Review

DOPD 处理的是 OPD 在“特权信息可用”场景中的一个尖锐问题：训练期给教师或学生额外提示，确实可能提高短期监督质量，但这种提升未必来自教师可迁移能力，而可能来自教师拥有学生部署时拿不到的信息。若直接让学生模仿这种输出，训练目标会把能力差距和信息差距混在一起，形成论文所谓 privilege illusion。

这篇论文的关键判断是：privileged context 下并非所有 token 都同等可教。少数 token 承载真正的能力差距，另一些 token 只是答案泄漏、提示残留、连接词、局部探索或不可靠片段。DOPD 因此放弃把 teacher logits 当作统一监督源，改为把每个 token 放入四种路由区域，分别采用强教师蒸馏、轻教师蒸馏、弱学生自正则和轻学生蒸馏。

一句话评价：DOPD 是一篇问题意识强于形式复杂度的论文。它没有把 privileged information 当作免费午餐，而是把“什么时候该相信 teacher，什么时候该相信 student，什么时候只做弱正则”变成 token 级别的训练策略。

贡献质量

“privilege illusion”是有解释力的 failure mode，尤其适用于 RLAIF、OPD、teacher-guided post-training 和多模态标注场景。

实验质量

LLM、VLM、跨规模、持续学习、OOD、稳定性、特权输入形式、token、散度和消融都覆盖到，实验叙事完整。

主要扣分

特权输入依赖 GPT-5.4 生成和复核，代码数据未开放，路由阈值偏启发式，成本曲线披露不足。

02

问题定义：从 OPD 到 Privilege Illusion

传统 OPD 的训练逻辑是：学生从当前策略采样 trajectory，教师对学生生成的 token 提供密集监督，学生在自己的 on-policy 分布上向教师靠拢。这比离线 SFT 更能缓解 exposure bias，也比只看最终 reward 的 RL 提供更密集的 token 级信号。

问题出现在“训练时额外信息”被引入以后。比如 LLM 任务中给模型 step-wise hints，VLM 任务中给模型 bounding box、object label 或结构化视觉注释。直觉上，这些信息能让教师更可靠。但部署阶段学生并不拥有同等信息，因此教师的高置信 token 可能只是信息优势，不是可由学生内部化的能力优势。

DOPD 对这个现象的命名很准确：privilege illusion。论文并未否定特权信息的价值；关键在于，“特权信息造成的表现提升”和“教师本身更强造成的可迁移能力差距”必须被区分。若不区分，蒸馏会让学生模仿一个部署时不可达的条件分布。

论文的诊断路径

论文先比较三类 OPD 变体：只给教师特权信息、只给学生特权信息、两者都给。前两者早期有收益，但后期更容易出现性能回落和 entropy collapse。其含义是，单侧特权输入会制造训练信号不对称，使学生更容易形成对不可部署上下文的局部过拟合，而难以沉淀为稳定能力。

随后，论文将 token 级别的 privilege advantage gap 作为分析工具。若移除 high-advantage tokens，性能增益显著降低；移除 random 或 low-advantage tokens 影响较小。这说明关键监督信号并不平均分布在整条输出上。

03

方法机制：Dual On-policy Distillation

DOPD 的基本做法是让同一个学生在训练期有两个视角：部署学生只看原始输入，privileged student 在训练期额外看到特权信息。教师也在特权上下文下输出分布。路由器比较 privileged teacher 与 privileged student 对每个 token 的 log probability 差值，并结合两者对该 token 的概率高低决定监督源。

形式上，论文定义 privilege advantage gap `A_n`，用于度量第 `n` 个 token 上 privileged teacher 与 privileged student 的分歧。实际实现会丢弃 top 5% outliers，并在 batch 内归一化，再用平均值作为高低分界。这个设计不复杂，但把“谁更有资格教这个 token”落实为可计算的 gating 信号。

low Ahigh qThigh qS 轻教师蒸馏

teacher 与 student 在特权上下文中一致且置信度高。DOPD 用 Top-K reverse KL 和 `beta_l` 进行轻量教师蒸馏，目标是保持稳定共识，而不是过度放大已经一致的 token。

low Alow qTlow qS 弱学生自正则

双方都不置信，token 可能是连接词、低价值片段或不可靠路径。DOPD 转向 stopped privileged student，以 Top-K reverse KL 和更弱的 `beta_w` 做自正则。

high Ahigh qT 强教师蒸馏

teacher 在该 token 上呈现可信优势。DOPD 使用 full-vocabulary JS divergence 和单位权重，把这部分 token 作为主要能力迁移区域。

high Ahigh qS 轻学生蒸馏

student 在特权上下文中更自洽，可能代表可保留的探索分支或局部 reasoning path。DOPD 使用 stopped privileged student 的 Top-K reverse KL，避免强行贴近 teacher。

为什么叫 dual

“dual”的含义不止于简单混合两个 loss，监督源本身具有双侧选择：一侧是 privileged teacher，负责可迁移能力；另一侧是 privileged student，负责稳定学生自身在特权上下文中的合理探索。这个选择按 token 动态发生，而非样本级或任务级静态加权。

DOPD 的方法要素与审稿判断
要素论文实现评审判断
优势估计比较 privileged teacher 与 privileged student 的 token log probability，得到 `A_n`。简单、可实现、可解释，但仍是 heuristic proxy。
token 路由按 `A_n`、`q_T`、`q_S` 划分四类 token，并选择不同监督源。是论文最实质的设计，直接回应 privilege illusion。

训练稳定性、持续学习与 OOD

论文报告 DOPD 在 LiveBench 上约 step-80 即超过若干强 baseline 的 step-200 表现；entropy 早期小幅上升、随后下降，并在 step-110 后趋于稳定。自蒸馏路线则在约 step-95 出现 entropy collapse 和性能下滑。这个结果支持作者的解释：单一自监督源容易变得同质化，而 dual routing 能维持必要探索。

在 continual learning 设定中，作者按 general、reasoning、coding 三阶段顺序训练，并观察到 DOPD 对新域持续增益，对旧域只有小幅退化。在 OOD 设定中，分别在 coding 或 reasoning 数据上优化，再到另一域评测，DOPD 分别超过第二名 3.1 和 4.3 分。这里的证据仍是作者实验，但覆盖面足够支撑“DOPD 不只是单表格调优”的判断。

05

深入评价：强点、弱点与真实创新

强点一：失败模式定义清楚

许多蒸馏论文把 teacher 更强当作默认前提，把监督源质量当作外生常量。DOPD 的进步在于它指出：一旦 teacher 或 student 看到特权上下文，teacher 的优势不再天然等价于能力优势。这个问题在多模态、工具调用、检索增强、自动标注和复杂 reasoning 数据生成中都会出现。

强点二：方法与诊断高度对齐

论文没有只停留在现象描述，而是把 privilege advantage gap 落到 token routing 上。high-gap, high-teacher-probability token 被视为能力迁移核心；low-gap 或 low-confidence token 不再被同等强度蒸馏。这样的设计避免了“整段输出同一个 loss”的粗糙性，也使实验消融更容易解释。

强点三：实验矩阵较完整

论文覆盖 9 个 LLM baseline 和 4 个 VLM baseline，另有跨模型规模、特权输入形式、token 分类、散度选择、持续学习、OOD 和稳定性分析。尤其是 privileged information analysis 与 token ablation，把方法收益从“模型更强了”追溯到“哪类训练信号有价值”，这比单纯报告平均分更有审稿价值。

弱点一：复现链条依赖外部强模型

论文使用 GPT-5.4 生成 LLM hints 与 VLM annotations，并再次用 GPT-5.4 复核后筛选出 32K 和 25K 训练样本。这带来三个问题：成本较高，外部模型可得性影响复现，数据本身可能继承 GPT-5.4 的偏置或隐含知识分布。即使 OpenAI 官方页面确认 GPT-5.4 于 2026-03-05 发布，这也不等于 DOPD 数据构造过程可复现。

弱点二：路由规则仍是启发式

`A_n` 以 log probability gap 衡量，batch 内丢弃 top 5% outliers 并归一化，然后用平均水平划分高低。这在论文实验中有效，但没有保证在长上下文、不同 tokenizer、不同语言、不同视觉粒度和工具调用轨迹中稳定。high `A_n` 可能仍包含信息泄漏，low `A_n` 也可能隐藏共享能力信号。

弱点三：成本披露不足

DOPD 相比 Vanilla OPD 至少需要额外 student forward pass，且 selected teacher-critical tokens 使用 full-vocabulary JS divergence。论文给出了 GPU、batch、step、Top-K 和系数设置，却没有充分报告 wall-clock、显存、吞吐、特权输入生成成本和单位增益成本。对工业落地而言，这部分缺失会影响优先级判断。

06

工程启示：何时值得采用 DOPD

DOPD 的优先场景并非普通 teacher-student compression；它更适合训练期存在额外标注、检索、视觉定位、解释、工具轨迹或专家提示，但部署期学生无法直接访问这些信息的后训练系统。

适用场景

  • 小模型承接大模型 reasoning、coding 或视觉推理能力，且 teacher-student gap 较大。
  • 训练数据可提供中等强度提示，例如 step hints、证据定位、object labels、检索片段或专家摘要。
  • 团队希望减少直接答案泄漏导致的 shortcut learning，而不是追求最短期训练集指标。
  • 需要保留学生自身探索路径，避免全量强教师蒸馏带来的 entropy collapse。

不宜直接采用

  • 没有可靠特权输入，或特权输入只能是最终答案。
  • 成本预算极紧，无法承受额外 forward pass、teacher logits 和 full-vocabulary divergence。
  • 业务要求极强可解释审计，而训练数据生成依赖不可公开的外部模型。
  • 任务分布变化很快，token routing 阈值无法被周期性重校准。

07

局限、可复现性与证据边界

DOPD 是强论文，但不能被解读为“OPD 已解决”或“特权信息总能提升蒸馏”。更准确的结论是：在作者给定的 Qwen3/Qwen3-VL、GPT-5.4 生成特权输入、固定 benchmark 和有限步数训练环境中，优势感知双源路由显著优于静态 OPD、自蒸馏和若干 adaptive baseline。

最终判断

DOPD 对 OPD 的贡献是把“教师强不强”改写为“这个 token 上的教师优势是否可迁移”。这是一种更接近后训练真实问题的视角。论文没有证明所有 privileged-context distillation 都应采用 DOPD，但它足够有力地说明：在训练期额外信息存在时，简单强教师模仿已经不是合格基线，至少应当加入 token 级别的信息不对称诊断。
