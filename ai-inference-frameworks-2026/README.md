# AI Inference Frameworks 2026

面向工程选型的大模型、多模态大模型与生成模型推理框架技术报告。

## Files

- `index.html`: 可读与可打印的报告源码。
- `ai-inference-frameworks-2026.pdf`: PDF 成品。
- `sources.md`: 一手来源、方法说明与边界。
- `data/repository-metadata.tsv`: 公开仓库元数据，用于辅助判断项目活跃度、许可与维护状态。

## Scope

报告覆盖在线推理服务引擎、本地与边缘推理运行时、分布式推理编排、多模态与结构化输出组件、图像与视频生成推理工作流。训练框架、Agent 应用框架、向量数据库、评测平台和云厂商托管产品不作为主体展开。
