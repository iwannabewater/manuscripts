# Generative Recommendation 2026

生成式推荐（Generative Recommendation, GR）的发展史、主流算法、产业落地和趋势判断报告。

## Files

- `index.html`: 可读与可打印的报告源码。
- `generative-recommendation-2026.pdf`: PDF 成品。
- `sources.md`: 一手来源、方法说明与边界。
- `fonts/`: PDF 使用的本地中文字体。

## Scope

报告覆盖推荐系统从协同过滤、矩阵分解、深度排序、序列建模到生成式推荐的主要技术脉络，并重点展开语义 ID、生成式检索、序列转导、LLM 增强推荐、扩散推荐、生成式重排、多模态推荐、推荐智能体与产业系统落地。广告、内容流、电商、视频、搜索推荐和本地生活等场景均按公开资料纳入，但不对未公开生产系统做未经证实的细节推断。
