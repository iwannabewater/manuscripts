# World Models 2026

世界模型（World Models）的发展史、主流算法、产业落地和趋势判断报告。

## Files

- `index.html`: 可读与可打印的报告源码。
- `world-models-2026.pdf`: PDF 成品。
- `sources.md`: 一手来源、方法说明与边界。
- `data/source-map.tsv`: 正文来源编号与 URL 映射。
- `fonts/`: PDF 使用的本地中文字体。

## Scope

报告覆盖世界模型在模型式强化学习、预测表征学习、视频世界模拟、交互式环境生成、机器人学习、自动驾驶仿真、3D/4D 空间智能和产业平台中的主要技术脉络。OpenAI Sora、Google DeepMind Genie / MuZero / Dreamer、NVIDIA Cosmos、Meta V-JEPA、Waymo World Model、Wayve GAIA、Runway GWM、World Labs Marble、Tencent HunyuanWorld、ByteDance IRASim 等公开材料均按来源口径纳入。未公开生产系统、未验证业务指标和无法追溯的投资/产品传闻不作为事实展开。
